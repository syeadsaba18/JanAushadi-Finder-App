# 💊 Jan Aushadi Finder App

A smart Android application that helps users quickly locate nearby Jan Aushadi medical stores and find affordable generic medicines. The app is designed to improve accessibility to low-cost healthcare services with a clean and user-friendly interface.

---

# 🚀 Project Overview

Jan Aushadi Finder App is an Android-based application developed to help users search for Jan Aushadi stores, explore medicine availability, and access affordable healthcare resources efficiently.

The application aims to bridge the gap between users and affordable medicines by providing an easy-to-use platform with location-based search and medicine information features.

This project was built as part of a practical software development initiative to enhance skills in mobile app development, UI/UX design, and backend integration.

# ⚙️ Installation Steps

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/syeadsaba18/JanAushadi-Finder-App.git
```

## 2️⃣ Open in Android Studio

- Launch Android Studio
- Click on **Open**
- Select the cloned project folder

## 3️⃣ Sync Gradle

Wait for Gradle dependencies to install automatically.

## 4️⃣ Run the Application

- Connect an Android device or emulator
- Click ▶ Run
